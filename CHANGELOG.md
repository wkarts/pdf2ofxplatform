# Changelog

## [1.0.0] - 2026-07-28

- Aplicação web Laravel para upload, acompanhamento, revisão e download.
- Serviço FastAPI e workers Celery.
- Parsers iniciais de Itaú, Banco do Nordeste e Santander.
- OCR com Tesseract para PDFs sem camada textual.
- Exportação OFX 1.02 SGML em Windows-1252.
- Docker Compose, CloudPanel Reverse Proxy, GHCR, CI, release e deploy.
